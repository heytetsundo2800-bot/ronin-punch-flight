# 浪人パンチフライト

一浪の空で、殴りあえ。スマホのブラウザでそのまま遊べる、4対4の360°空中バトル。

グレンジの『キックフライト』（2020〜2021年）の遊びかたを手本にしたファンメイドのゲームです。公式とは関係ありません。

## 遊び方（操作）

| 操作 | 動き |
|---|---|
| 長押し | 前へ飛ぶ（地面では走る）。離すとその場で止まる |
| 長押し＋スライド | 飛びながら旋回（押した所にスティックが出る） |
| 押してすべらせる（はなさない） | 止まったまま向きを変える（すばやく離すとステップ） |
| タップ | ブーストダッシュ（ゲージ1つ）。そのあと自動で飛び続ける |
| 横フリック | 止まっている：ステップ／飛んでいる：バレルロール |
| 上フリック | 止まっている：上昇 |
| 下フリック | 止まっている：バックステップ／飛んでいる：急ブレーキ |
| 上と下のフリックを続けて | 180度ターン（ロックオンは外れる） |
| 右の顔アイコン | タップでロックオン → 近づくと自動でパンチ |
| 下のアイコンを上フリック | スキル（ディスク・パンチャースキル） |
| ディスクを下フリック | その色の属性に変える（火＞風＞水＞火） |
| SPボタン | スペシャル |

ジャスト回避（攻撃の直前にフリック）、壁キック（壁へブースト）、ダッシュ攻撃（ロック中にタップ、ゲージ2つ）もあります。

## ディスク（モンスターの技）

キックフライトのディスクと同じく、ディスクはモンスターの技をキャラに付ける。使うと六角形の光からモンスターがキャラの右前に出て、その口から技が出る。溜めているあいだに強い攻撃を受けると、モンスターが割れて技は出ない。レア度（N・R・SR）が高いほど、呼び出しが派手（SRは光の柱）。

| ディスク | 種類 | 属性 | 技 |
|---|---|---|---|
| ブレイズドレイク | ATK | 火 | ホーミングフレア（追いかける火の玉） |
| ゲイルファルコン | ATK | 風 | ゲイルブーメラン（行って帰るかまいたち） |
| ランスナーヴァル | ATK | 水 | アクアランス（まっすぐ速い水の槍） |
| ヒールジェリー | HEAL | 水 | ヒールバブル（HP30%回復） |
| スリープアウル | HEAL | 風 | ムーンララバイ（近くの味方も少しずつ回復） |
| ブレイブレオ | BUFF | 火 | ブレイブロア（攻撃力アップ） |
| ブリッツチーター | BUFF | 風 | ブリッツアクセル（スピードアップ） |
| アイギスタートル | BUFF | 水 | アイギスシェル（バリア） |
| ボムビートル | TRAP | 火 | ビートルボム（その場に爆弾虫） |
| グリッドオクトパス | TRAP | 水 | グリッドフィールド（敵がおそくなる結界） |
| フェイズフォックス | WARP | 風 | フェイズシフト（前へ瞬間移動） |
| ホタルゲート | WARP | 水 | ホームゲート（ダルマの前へ） |
| ロケットボア | MOVE | 火 | ロケットチャージ（大きくダッシュ） |
| スカイスワロー | MOVE | 風 | スカイステップ（ブースト全回復） |

ホームの「ディスク」で4枚を選ぶ。上の窓で、選んだモンスターが3Dで技の動きを見せる。モンスターはすべてこのゲームのオリジナル（`src/monsters.js` で、丸・円すい・曲がった管・切りぬいた板を組み合わせて作っている）。

## ルール

- **スクランブル**：サクラ50個を集めて、3分後に多いチームの勝ち。ダルマに預けると倒されてもなくならない
- **フラッグフライト**：敵陣に出る自分の色の旗をゴールへ。先に3本で勝ち
- **ラピッドボール**：敵のダルマを倒してリングを開け、ボールを持ってくぐる。残り1分で10点のボール

## ステージ

ホームの「ステージ」を押すと切りかわる（おまかせ＝毎回どちらか）。オンラインの部屋ではホストが選ぶ。

- **サクラ浮島**（昼）：合格祈願の神社がうかぶ空。まん中に本殿、くぐれる鳥居
- **あこがれキャンパス**（夕焼け）：受かったら通いたい大学。まん中に時計台、中くらいの島どうしを渡り廊下がつなぐ（上も下も通れる）。陣地には校門、あずまや・天文台・校舎の屋上にもサクラ

陣地・ダルマ・ゴールリングの場所はどちらも同じ。

## フレンドとオンライン対戦（ベータ）

ホームの「フレンドとオンライン対戦」→「部屋をつくる」で5けたの部屋コードが出る。LINEで招待リンクを送るか、コードを入れてもらう。最大8人、あいた席はCPU。

- つなぎかた：サーバー（`/api/rpf`）は最初のあいさつ（WebRTC の SDP）を受けわたすだけ。試合中は端末どうしが直接つながる
- 部屋をつくった人（ホスト）の端末が、CPU・当たり判定・ルールを計算して、みんなに状態を送る（1秒に20回）
- 入った人は、自分のキャラだけその場で動かす（操作のおくれをなくす）。ほかの人は少し前の状態をなめらかにつないで表示する
- 試合中は味方にスタンプ（ナイス！・集まれ！など）を送れる。人の頭の上に名前と体力、右上に通信の速さ（ms）
- つながらない組み合わせ（モバイル回線どうし・学校のWi-Fiなど）があるときは、TURN サーバーを足すとつながりやすくなる（下の環境変数）

## 見た目の作り方（v1.4）

キックフライト・#コンパス・ONE PIECE バウンティラッシュの画面の作り方を調べて、同じ考え方で作っています（絵・キャラ・音はすべてこのゲームのオリジナル）。

- **アニメ塗り**（`src/gfx.js` の `cel`）：影は暗くするのではなく「影の色」をのせる2色の塗り。キャラはキャラ専用の光で照らす（顔がいつも明るい）。ふちにチームの色の光（敵味方がひと目でわかる）
- **ふちどり**：部品の色を暗くした線。太さは画面で 0.7〜2.6px におさめる（遠くても消えず、近くても太すぎない）
- **仕上げ**（`src/post.js`）：明るい物がにじむブルーム＋ステージごとの色の仕上げ（`GRADES`）。重い端末では自動で軽くする
- **キャラ**（`src/model.js`）：表情の絵を切りかえる顔（8種）、ポーズ、エモート。同じ塗りの部品は1つにまとめて「スキン」で動かす（描く回数を約1/6に）
- **足もとの影**（`src/shadow.js`）：真下の床に丸い影（高いほど小さく・うすく）
- **必殺技のカットイン**（`src/main.js` の `cutin`、`src/theme.css` の `.spcut`）と、結果画面の勝ち・負けポーズ（`src/portraits.js` の `cut`・`hero`）
- **ステージ**（`src/stage.js`・`src/stageart.js`）：島の岩は地層・石のかたまり・ひび・コケ・土の層をシェーダーで描く。草は色むらと落ちた花びら（キャンパスはイチョウの葉）、ふちから垂れる草・つる。空は太陽の光と筋雲、雲は2色のセル影のかたまり、雲海はもこもこ。レンガ・石・瓦・木の模様は同じ大きさでそろえて貼る。当たり判定・アイテムの場所は前と同じ
- **エフェクト**（`src/fx.js`・`src/vfx.js`）：足のジェットから出るチーム色の光の帯、ヒットの星・衝撃の輪・のびる火花・強い攻撃の白い破片と集中線、マンガの擬音文字（ドゴッ! など）、セル塗りのけむり。まとめ描きで、描く回数は最大でも4回
- **ロビー**（`src/lobbyart.js`）：タイトル・ホームの背景もステージと同じ描き方
- 自作のシェーダーは「linear の色を出して、最後に `#include <colorspace_fragment>`」がきまり

## 開発

```bash
npm install
npm run dev      # public/ に開発用ビルド
npm run build    # 本番ビルド（Vercel もこれを実行）
```

- `src/` ゲーム本体（three.js）
- `web/` HTML・アイコン・サービスワーカー
- `api/rpf.js` アカウント・ランキングのサーバー（Vercel Functions ＋ Upstash Redis、キーは `rpf:` で始まる）
- `tools/` ビルドと自動テスト（Playwright）
- `tools/music/bgm.py` BGMをコードで作る（numpy＋ffmpeg）。`python3 tools/music/bgm.py all <出力先>` で `bgm_lobby` と `bgm_battle` の m4a・mp3 ができる。`web/` に置くと、ゲームがつなぎ目なしでループさせる（メモリを食わないように、展開するのは鳴らしている曲だけ。もう1曲は圧縮のまま持つ。BGMの音量が0のときは読みこまない）

データベースの環境変数：`KV_REST_API_URL` と `KV_REST_API_TOKEN`（Vercel の Storage で Upstash をつなぐと入る）。無いときもゲームは遊べる（記録は端末だけ）。

オンライン対戦の TURN（なくても動く。つながりにくいときだけ）：
- `METERED_DOMAIN` と `METERED_API_KEY`：Metered の Open Relay（無料で登録、月20GBまで）
- または `CF_TURN_KEY_ID` と `CF_TURN_KEY_TOKEN`：Cloudflare の TURN
- または `RPF_ICE`：ICE サーバーの JSON 配列をそのまま

テスト：`node tools/api/api_test.js`、`node tools/api/room_test.js`、`node tools/api/devserver.js --port 8813` を動かして `python3 tools/acct_e2e.py`・`python3 tools/online_e2e.py [scramble|flag|ball] [sakura|campus]`・`python3 tools/online_lag.py 150 80 0.1`・`python3 tools/stage_test.py`（ステージの物がサクラやボールにめりこんでいないか）。`public/` を 8812 で配信して `python3 tools/ctrl_test.py`・`tools/tut_test.py`・`tools/modes_test.py`・`tools/disc_test.py`（ディスクのモンスター）・`tools/bgm_test.py`（BGM）
