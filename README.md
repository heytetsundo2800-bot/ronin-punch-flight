# 浪人パンチフライト

一浪の空で、殴りあえ。スマホのブラウザでそのまま遊べる、4対4の360°空中バトル。

グレンジの『キックフライト』（2020〜2021年）の遊びかたを手本にしたファンメイドのゲームです。公式とは関係ありません。

## 遊び方（操作）

操作のしかたは2つ（せっていの「操作のしかた」で切りかえ）。はじめは **両手**。

- **両手**（左の親指はアクセル・右の親指で視点）：画面の左半分は **アクセルだけ**（長押しで飛ぶ・はなすと止まる。タップでブースト、フリックで回避。すべらせても向きは変わらない）。右半分は **なぞると視点（向き）が動く**（飛びながらでも、止まっていても。右へなぞる＝右を向く、上へなぞる＝上を向く）。右半分のタップもブースト。視点の速さは「視点の速さ（右の親指）」で変えられる
- **片手**（画面のどこでも）：下の表の操作を画面のどこでも（キックフライトと同じ）

| 操作 | 動き |
|---|---|
| 長押し | 前へ飛ぶ（地面では走る）。離すとその場で止まる |
| 長押し＋スライド（片手） | 飛びながら旋回（押した所にスティックが出る） |
| 右の親指でなぞる（両手） | 視点（向き）を動かす。カメラは指にぴったりついてくる |
| 押してすべらせる（片手・はなさない） | 止まったまま向きを変える（すばやく離すとステップ） |
| タップ | ブーストダッシュ（ゲージ1つ）。そのあと自動で飛び続ける |
| 横フリック | 止まっている：ステップ／飛んでいる：バレルロール |
| 上フリック | 止まっている：上昇 |
| 下フリック | 止まっている：バックステップ／飛んでいる：急ブレーキ |
| 上と下のフリックを続けて | 180度ターン（ロックオンは外れる） |
| 右の顔アイコン | タップでロックオン → 近づくと自動でパンチ |
| 右の親指で敵をタップ（両手） | その敵にロックオン（v1.7） |
| 下のアイコンを上フリック | スキル（ディスク・パンチャースキル） |
| ディスクを下フリック | その色の属性に変える（火＞風＞水＞火） |
| SPボタン | スペシャル |

ジャスト回避（攻撃の直前にフリック）、壁キック（壁へブースト）、ダッシュ攻撃（ロック中にタップ、ゲージ2つ）もあります。飛んでいて壁にぶつかると、止まらずに壁にそってすべる（v1.7）。サクラは自分のダルマに近づくだけで自動で預ける（v1.7。前の「預ける」ボタンはなくなった）。

## ルール

- **スクランブル**：サクラ50個を集めて、3分後に多いチームの勝ち。ダルマに預けると倒されてもなくならない
- **フラッグフライト**：敵陣に出る自分の色の旗をゴールへ。先に3本で勝ち
- **ラピッドボール**：敵のダルマを倒してリングを開け、ボールを持ってくぐる。残り1分で10点のボール

くわしい説明（勝ち方・気をつけること・コツ・図）はゲームの中にある（ホームのモードの「ルール」、せってい、あそび方）。中身は `src/rules.js`。ルールを変えたら、ここも直す。

## フレンドとオンライン対戦（ベータ）

ホームの「フレンドとオンライン対戦」→「部屋をつくる」で5けたの部屋コードが出る。LINEで招待リンクを送るか、コードを入れてもらう。最大8人、あいた席はCPU。

- v1.8：**フレンドを招待**（ブロスタのように）。部屋の「フレンドを招待」に、フレンドが「オンライン・部屋にいる・対戦中・オフライン」で出る。「招待」を押すと、相手の画面に「〇〇さんから招待！」と「参加する」が出て、押すとその部屋に入る（試合中の人には、試合が終わってから出る。招待は2分で消える）。ホームの「オンライン対戦」にも、オンラインのフレンドの数が出る
- v1.8：**試合のあとは同じ部屋の待ち画面にもどる**。結果のあと15秒で（ホストがもどったら、ほかの人も5秒で）自動でもどる。部屋は作りなおさずに、ルール・ステージ・CPU・チームを変えてもう1試合。まだ結果を見ている人には「結果画面」と出る。ホストの結果画面の左のボタンは「部屋をとじる」（たしかめてから、全員外に出る）
- v1.8：**フレンドコードのコピー**。「ランキング」→「フレンド」と「せってい」→「アカウント」に自分のコード（タップか「コピー」でコピー）。「友だちのコードで追加」は、LINEでもらった文やリンクをそのまま貼りつけてもコードを取り出す
- v1.8.1：**ホームにフレンドの欄**。左上（名前の下）に、フレンドの顔と「オンライン・部屋にいる・対戦中・オフライン」（顔の右下の点の色も同じ：緑・青・オレンジ・灰色）。オンラインの人が上、オフラインの人はうすく。見出しの「●2人」はオンラインの人数。押すと全員の一覧（そこから「フレンドを追加・コードを送る」）。人数が多いと「ほか N人」。フレンドがいないときは「フレンドを追加」ボタン。アカウントのない人には出さない
- オンラインのしるし：アプリを開いているあいだ、12秒ごと（試合中は45秒ごと）にサーバーへ `hb` を送る（`rpf:on:<uid>`、40〜100秒で消える）。フレンドに見えるのは状態だけで、部屋コードは招待を送ったときだけ（`rpf:iv:<uid>`、フレンドどうしだけ・1人10分20回まで）

- つなぎかた：サーバー（`/api/rpf`）は最初のあいさつ（WebRTC の SDP）を受けわたすだけ。試合中は端末どうしが直接つながる
- 部屋をつくった人（ホスト）の端末が、CPU・当たり判定・ルールを計算して、みんなに状態を送る（1秒に20回）
- 入った人は、自分のキャラだけその場で動かす（操作のおくれをなくす）。ほかの人は少し前の状態をなめらかにつないで表示する
- 試合中は味方にスタンプ（ナイス！・集まれ！など）を送れる。人の頭の上に名前と体力、右上に通信の速さ（ms）
- つながらない組み合わせ（モバイル回線どうし・学校のWi-Fiなど）があるときは、TURN サーバーを足すとつながりやすくなる（下の環境変数）

## v1.7 で変わったこと

**CPUの強さが6段階**（ホームとオンラインの部屋で ◀ ▶ で選ぶ。中身は `src/config.js` の `DIFFICULTY`）

| 段階 | どんなCPU |
|---|---|
| おさんぽ | 攻撃してこない。のんびり飛んでサクラを拾うだけ（敵のダルマも撃ってこない） |
| よわよわ | たまに攻撃してくるけど、ダメージはとても小さい。技は使わない |
| やさしい | 攻撃してくる。ダメージは小さめで、技はときどき（はじめはこれ） |
| ふつう | ふつうに戦う。技も使う |
| つよい | よけたり、技をどんどん使ったりする |
| 鬼 | ほぼ全力（前の版の「つよい」と同じくらい。前に「つよい」を選んでいた人は「鬼」になる） |

- 味方のCPUは、敵が「おさんぽ」「よわよわ」のときは「やさしい」、「やさしい」「ふつう」のときは「ふつう」の強さで助けてくれる。オンラインはCPU全員がホストの選んだ強さ
- もらえる点（ランク・週のポイント）は強さで変わる（おさんぽ 0.2倍〜鬼 1.5倍）。ただし1試合でランク +60・週のポイント +2500 まで（サーバーのチート対策の上限と同じ）。おさんぽ・よわよわでは負けても点はへらない。ディスクパックも弱い段階では出にくい（はじめての1回は必ず1つ）

**訓練場**（ホームの「訓練場」。中身は `src/training.js`）：時間制限なしで操作を練習する場所。

- サンドバッグの人数（1人・3人）と動き（止まる・動く・反撃・弱・反撃・強）を選べる。「サンドバッグを前に呼ぶ」で目の前に来る
- スキル・ディスクの待ち時間なし、SPをいつも満タン、無敵（無敵でもジャスト回避はちゃんと数える）を切りかえられる
- 練習メニュー（移動・攻撃・スクランブルの16こ。遠くから撃つキャラはダッシュ攻撃がなくて15こ）を上から順にやると、できたものにチェックがつく。与えたダメージ（1秒あたりも）が出る

**ルールの説明**（`src/rules.js`）：はじめてそのモードで戦うときに、ルールと勝ち方が図つきで出る。ホームのモードの「ルール」・せってい・あそび方からいつでも見られる。試合のカウントダウンのあいだは「勝ち方」がひとこと出る。

**てつんど**：とても強くした。

- 近くはスティック連打（4発目が強い）、遠く（30mまで）はビートショット（回るスティックが敵を追いかける。3発目が強い）。近くに敵がいないときは、ロックした敵か、前にいる敵を自動で撃つ
- 自動回復（とくせい「リズムキープ」）：いつも1秒にHPの1.5%、3秒攻撃を受けないと1秒に4%
- HP 3300・攻撃力も上げた。スキルのドラムロールも強く

**操作**

- 右の親指で敵をタップするとロックオン（もうロックしている敵をタップしたときは、ふつうのタップ＝ダッシュ攻撃）
- 右の親指のタップの判定をきびしく（0.24秒・8px 以内。なぞったつもりがブーストになりにくい）。すばやくなぞると視点が速く回る（最大1.6倍）
- 飛んでいて壁にぶつかると、壁にそってすべる（ステージのはしの見えない壁では、上にはすべらない）
- サクラは自分のダルマの近くで自動で預ける（「預ける」ボタンは「預け中」のしるしになった）

**見た目**

- パンチャー画面：キャラの一覧を1列にして、説明を小さくまとめた（「くわしく」で全部）。キャラがいつも一覧と説明のあいだに全身見えるように、画面の大きさに合わせてカメラを動かす
- エブン：頭のゴーグルのような出っぱりをなくした

**オンライン**：通信の約束を `PROTO 5` にした（ビートショットと、撃っている動きのしるしが増えた）。古い版の端末とは同じ部屋で遊べないので、ページを読みこみ直してもらう。

## 見た目の作り方（v1.4）

キックフライト・#コンパス・ONE PIECE バウンティラッシュの画面の作り方を調べて、同じ考え方で作っています（絵・キャラ・音はすべてこのゲームのオリジナル）。

- **アニメ塗り**（`src/gfx.js` の `cel`）：影は暗くするのではなく「影の色」をのせる2色の塗り。キャラはキャラ専用の光で照らす（顔がいつも明るい）。ふちにチームの色の光（敵味方がひと目でわかる）
- **ふちどり**：部品の色を暗くした線。太さは画面で 0.7〜2.6px におさめる（遠くても消えず、近くても太すぎない）
- **仕上げ**（`src/post.js`）：明るい物がにじむブルーム＋ステージごとの色の仕上げ（`GRADES`）。重い端末では自動で軽くする
- **キャラ**（`src/model.js`）：表情の絵を切りかえる顔（8種）、ポーズ、エモート。同じ塗りの部品は1つにまとめて「スキン」で動かす（描く回数を約1/6に）
- **足もとの影**（`src/shadow.js`）：真下の床に丸い影（高いほど小さく・うすく）
- **必殺技のカットイン**（`src/main.js` の `cutin`、`src/theme.css` の `.spcut`）と、結果画面の勝ち・負けポーズ（`src/portraits.js` の `cut`・`hero`）
- **ステージ**（`src/stage.js`・`src/stageart.js`）：島の岩は地層・石のかたまり・ひび・コケ・土の層をシェーダーで描く。草は色むらと落ちた花びら（キャンパスはイチョウの葉）、ふちから垂れる草・つる。空は太陽の光と筋雲、雲は2色のセル影のかたまり、雲海はもこもこ。レンガ・石・瓦・木の模様は同じ大きさでそろえて貼る。当たり判定・アイテムの場所は前と同じ
- **エフェクト**（`src/fx.js`・`src/vfx.js`）：足のジェットから出るチーム色の光の帯、ヒットの星・衝撃の輪・のびる火花・強い攻撃の白い破片と集中線、マンガの擬音文字（ドゴッ! など）、セル塗りのけむり。まとめ描きで、描く回数は最大でも4回
- **ロビー**（`src/lobbyart.js`）：タイトル・ホームの背景もステージと同じ描き方
- 自作のシェーダーは「linear の色を出して、最後に `#include <colorspace_fragment>`」がきまり

## 開発

```bash
npm install
npm run dev      # public/ に開発用ビルド
npm run build    # 本番ビルド（Vercel もこれを実行）
```

- `src/` ゲーム本体（three.js）
- `web/` HTML・アイコン・サービスワーカー
- `api/rpf.js` アカウント・ランキングのサーバー（Vercel Functions ＋ Upstash Redis、キーは `rpf:` で始まる）
- `tools/` ビルドと自動テスト（Playwright）
- `bgm_private/`（リポジトリには入れない）：Suno の曲（`bgm_lobby.m4a`・`.mp3`、`bgm_battle.m4a`・`.mp3`）と `loops.json`（`{"lobby": {"start": ループのはじめ（秒）, "end": ループの終わり, "play": 0}, "battle": {...}}`）。あれば `tools/build.mjs` がこちらを使い、ループの位置をゲームに入れる。ファイルは［曲のはじめ〜ループの終わり（終わりの1拍は、ループのはじめの直前の1拍へ重ねて切りかえ）］＋［ループのはじめから0.5秒］なので、デコーダーのずれがあってもつなぎ目がずれない
- `tools/music/bgm.py` BGMをコードで作る（numpy＋ffmpeg）。`python3 tools/music/bgm.py all <出力先>` で `bgm_lobby` と `bgm_battle` の m4a・mp3 ができる。`web/` に置くと、ゲームがつなぎ目なしでループさせる（メモリを食わないように、展開するのは鳴らしている曲だけ。もう1曲は圧縮のまま持つ。BGMの音量が0のときは読みこまない）

データベースの環境変数：`KV_REST_API_URL` と `KV_REST_API_TOKEN`（Vercel の Storage で Upstash をつなぐと入る）。無いときもゲームは遊べる（記録は端末だけ）。

オンライン対戦の TURN（なくても動く。つながりにくいときだけ）：
- `METERED_DOMAIN` と `METERED_API_KEY`：Metered の Open Relay（無料で登録、月20GBまで）
- または `CF_TURN_KEY_ID` と `CF_TURN_KEY_TOKEN`：Cloudflare の TURN
- または `RPF_ICE`：ICE サーバーの JSON 配列をそのまま
